# 5/3/1 Calculator

A single-screen calculator that turns four Training Maxes into the weights for one 5/3/1 cycle. No assistance work.

## Language

**Training Max (TM)**:
The load every 5/3/1 percentage is calculated from. Entered directly per lift; this app does not derive it from a 1RM.
_Avoid_: 1RM, max, true max

**Exercise**:
A named slot holding a Training Max and the resulting cycle of weights. Its label is free text, so the calculator is not tied to any fixed set of lifts.
_Avoid_: main lift, movement, lift

**Cycle**:
One four-week block of 5/3/1 training: three working weeks followed by a deload week.
_Avoid_: block, mesocycle, month

**Week**:
One of the four weeks in a cycle. Weeks 1–3 are working weeks (5s, 3s, 5/3/1); week 4 is the deload.
_Avoid_: session, day

**Working Set**:
One of the three prescribed percentage sets for a lift in a working week.
_Avoid_: work set, main set

**Top Set**:
The third working set, performed for as many reps as possible (AMRAP). Written as 5+, 3+, or 1+.
_Avoid_: AMRAP set, plus set, money set

**Warm-up Set**:
A light preparatory set at 40/50/60% of the Training Max, done before the working sets.
_Avoid_: ramp, warmup

**Deload**:
The fourth week of a cycle, trained at 40/50/60% for 5 reps to recover.
_Avoid_: rest week, light week

**Doing Jack Shit**:
The assistance template that adds no assistance work; only the main lift is trained. The scope of this app.
_Avoid_: base template, minimal template, no-assistance
