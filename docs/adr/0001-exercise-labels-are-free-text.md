# Exercise labels are free text

Each card's exercise is a free-text label, not a choice from the four main lifts. This makes the calculator generic — any named slot can hold a Training Max and produce a 5/3/1 cycle — rather than a squat/bench/deadlift/overhead-press app. We chose it because hard-coding four lifts buys no behaviour and blocks reuse for other movements; the four main lifts survive only as default label text.
